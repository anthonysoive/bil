Bil — Multiphysics Simulation Platform
=======================================

**Bil** is a scientific computing platform for multiphysics simulations using
finite element (FEM) and finite volume (FVM) methods. It targets applications
in poromechanics, cement chemistry, diffusion, and materials science.

- Source: https://github.com/Universite-Gustave-Eiffel/bil
